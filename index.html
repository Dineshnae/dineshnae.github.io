What I do

Engineering tasks for AI training and evaluation

A task is a problem statement in the voice of a stress or manufacturing office, a disclosed engineering standard, a verified reference solution, and an automated grader that accepts any valid answer and rejects the textbook shortcut. I build all four, calibrate difficulty against repeated agent runs, and run the result in Docker with a separate verifier image and held-back cases.

Verifier and grader review

Units, equilibrium and load paths, boundary conditions, mesh-independence, solver health and convergence, reference frames, reproducibility with pinned dependencies, fail-closed numerics, and the bypasses: can a submission pass without the engineering? Each check is backed by a battery where valid alternative constructions pass and naive methods fail by a clean margin.

The engineering underneath
